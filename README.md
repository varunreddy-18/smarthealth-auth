# 🏥 SmartHealth Auth

A role-based Healthcare Identity and Access Management (CIAM) platform built using **FastAPI, React, MySQL, JWT, and Google OAuth**.

SmartHealth Auth provides secure authentication and role-based access for healthcare users such as **Patients, Doctors, Pharmacists, and Admins**.

---

## ✨ Features

- User registration with role selection
- Secure login using JWT authentication
- Secure refresh-token rotation (refresh tokens with rotation and expiration)
- Rate limiting on authentication endpoints (login/register/google login)
- Password hashing using BCrypt
- Google OAuth login
- Role-Based Access Control (RBAC)
- Protected backend API routes
- Protected React routes
- JWT expiration validation
- Automatic login using stored JWT
- Secure logout and session revocation
- User session tracking
- Role-specific dashboards
- MySQL database integration
- Automated authentication/RBAC tests (pytest)

| Role | Access |
|---|---|

## 🚀 Installation and Setup

### 1. Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/smarthealth-auth.git

cd smarthealth-auth
```

Replace `YOUR_USERNAME` with your GitHub username.

---

## Backend Setup

### 1. Navigate to the backend

```bash
cd backend
```

### 2. Create a virtual environment

```bash
python -m venv venv
```

### 3. Activate the virtual environment

#### Windows

```bash
venv\Scripts\activate
```

#### macOS/Linux

```bash
source venv/bin/activate
```

### 4. Install dependencies

```bash
pip install -r requirements.txt
```

### 5. Create a `.env` file

Create:

```text
backend/.env
```

Add your own configuration:

```env
DATABASE_URL=mysql+pymysql://USERNAME:PASSWORD@localhost/smarthealth_auth

SECRET_KEY=your_secret_key
ALGORITHM=HS256
ACCESS_TOKEN_EXPIRE_MINUTES=60

GOOGLE_CLIENT_ID=your_google_client_id
GOOGLE_CLIENT_SECRET=your_google_client_secret
```

> Never upload the `.env` file to GitHub.

### 6. Start the backend

Run this from the `backend` folder:

```bash
uvicorn app.main:app --reload
```

Backend URL:

```text
http://127.0.0.1:8000
```

API documentation:

```text
http://127.0.0.1:8000/docs
```

## 📌 Main API Endpoints

| Method | Endpoint | Description |
|---|---|---|
| POST | `/auth/register` | Register a new user |
| POST | `/auth/login` | Authenticate user and generate JWT |
| POST | `/auth/refresh` | Exchange refresh token for new access + refresh tokens |
| POST | `/auth/logout` | Invalidate session and revoke refresh token |
| GET | `/auth/google/login` | Start Google OAuth login |
| GET | `/auth/google/callback` | Google OAuth callback |
| GET | `/health` | Check API health |
| GET | `/docs` | Open Swagger API documentation |
